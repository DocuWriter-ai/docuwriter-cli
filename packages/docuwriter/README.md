# DocuWriter CLI

Start documentation from your project folder:

```sh
npx docuwriter
```

Requires Node.js 22.18 or later and a DocuWriter account. Sign in or create an account through the browser, then generate documentation or import existing Markdown files. Follow progress in your DocuWriter Space after upload.

This launcher runs the official [@docuwriter-ai/cli](https://www.npmjs.com/package/@docuwriter-ai/cli) package. For usage, privacy, and support, see the [CLI guide](https://github.com/DocuWriter-ai/docuwriter-cli#readme).
